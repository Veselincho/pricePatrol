# pricePatrol

pricePatrol is a GitHub-backed browser extension for saving product prices, tracking reference snapshots, and reviewing price history over time.

The repository is the source of truth:

- `data/prices.json` stores the tracked products and snapshot history
- `data/screenshots/` stores reference screenshots generated by the daily workflow
- GitHub Actions runs the checks once per day and commits updates back into the repository

## How it works

1. You open a product page in your browser.
2. The extension lets you save the current price into your connected GitHub repository.
3. The save updates `data/prices.json` and triggers the daily GitHub Actions workflow.
4. GitHub Actions checks the saved products, compares the current price with the last reference, and captures a screenshot when the price changes or when a first baseline is needed.
5. The dashboard in the extension shows:
   - current price
   - price history over time
   - reference days
   - links to stored screenshots

## How to use the extension

### 1) Connect your GitHub repository
Open **Settings** inside the extension and enter:

- GitHub repository in `owner/repo` format, for example `Veselincho/pricePatrol`
- a GitHub Personal Access Token with write access to the repository
- the branch name if your default branch is not `main`

### 2) Save a price
- Open the product page you want to track.
- Click the extension icon.
- Press **Save current price**.
- Confirm or adjust the value in the picker.
- The item is stored in your repository and the workflow is dispatched.

### 3) Review the product dashboard
- In the extension popup, click a product row.
- The dashboard opens with price history, reference days, and screenshot links.

## What gets stored

The extension writes the following data into the repository:

- `data/prices.json` with the tracked products and snapshots
- `data/screenshots/` with the reference images produced by GitHub Actions

## GitHub Actions

For the workflow to commit back into the repository, GitHub must allow write access for Actions.

### Required repository setting

In your GitHub repository:

1. Go to **Settings**
2. Open **Actions** → **General**
3. Under **Workflow permissions**, select **Read and write permissions**
4. Save the setting

The workflow itself also declares:

```yaml
permissions:
  contents: write
```

That allows the built-in `GITHUB_TOKEN` to commit and push changes back to the repo.

## Browser extension install

Load the `extension/` folder as an unpacked extension.

### Chrome / Edge / Brave

1. Open `chrome://extensions` or `edge://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select the `extension/` folder

### Firefox

1. Open `about:debugging#/runtime/this-firefox`
2. Click **Load Temporary Add-on**
3. Select `extension/manifest.json`

## Notes

- Screenshots are stored as repo-relative paths, so they work cleanly in forks and in committed JSON data.
- The extension is designed to work without a local backend server.
- Keep the repository write permissions enabled for Actions, or the automation will not be able to update the data.
